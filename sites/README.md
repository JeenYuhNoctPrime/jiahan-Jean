# Personal Sites

Each person gets a folder here. **Rename** `teen-one` and `teen-two` to your actual names (lowercase, no spaces — use hyphens).

## Structure per site

```
sites/your-name/
├── index.html       # Home page
├── about.html       # About you
├── journal.html     # Journal index
├── css/style.css
├── js/main.js
└── journal/         # One markdown file per entry (convert to HTML later)
```

## Open locally

Double-click `index.html` or use Cursor's Live Preview extension.
