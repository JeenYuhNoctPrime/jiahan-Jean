# Optional HTML Starter

Hand-coded HTML/CSS sites from the original repo layout. **Not the main learning path** — use Quarto in `sites/your-name/` instead.

## When to peek here

- Week 3+ curiosity: "What does Quarto generate under the hood?"
- Compare your `.qmd` output in `_site/` with these source files
- Optional CSS/HTML deep dive for the 16yo who wants it

## How to open

Double-click `jiahe-yu/index.html` or `jiahan-yu/index.html` in a browser.

These folders are **not** connected to Quarto — standalone static HTML.
