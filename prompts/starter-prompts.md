# Starter Prompts — Copy, Paste, Customize

Replace `[brackets]` with your details. Save prompts that work well in your own `my-prompts.md`.

---

## Understanding code

```
I'm [14/16] and new to [HTML/CSS/JavaScript]. Explain @[filename]
line by line in plain language. Skip jargon or define it when you use it.
```

---

## Building features

```
In sites/[my-name]/, add a [feature]. Requirements:
- [bullet 1]
- [bullet 2]
Keep the existing color scheme. Show me the plan before editing files.
```

---

## Styling

```
My site feels boring. Suggest 3 visual improvements that don't require
new images. Implement the one I pick: [1/2/3].
```

---

## Debugging

```
When I open index.html in Chrome, [describe problem]. Here's what I
expected: [expected]. Files involved: @[file1] @[file2]. Fix it and
explain the root cause in 2 sentences.
```

---

## Journal workflow

```
Create a new journal markdown file for today titled "[title]". Use the
same front matter format as my other entries in journal/. Include
sections: What I did, What I learned, Tomorrow.
```

---

## Learning mode (ask AI to teach, not do)

```
Don't write the code yet. Guide me step by step to add [feature] myself.
Give me one step, wait for me to say done, then give the next step.
```

---

## Code review

```
Review sites/[my-name]/index.html and style.css like a friendly teacher.
List 3 things done well and 3 improvements. Don't change files yet.
```

---

## Compare tools (Week 6)

```
Add a footer with copyright and links to GitHub and journal. Use minimal
changes. After you're done, list which files you touched and why.
```

Run the same prompt in Cursor, then try completing similar work with Copilot inline.

---

## Anti-patterns (prompts that give bad results)

❌ "Make my website cool"  
✅ "Add a hero section with my name, one sentence bio, and a blue gradient background"

❌ "Fix everything"  
✅ "The nav links overlap on screens under 400px wide — fix the media query"

❌ Pasting homework answers  
✅ "Explain this concept so I can solve similar problems myself"
