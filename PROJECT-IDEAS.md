# Project Ideas — Pick Your Adventure

Ranked roughly from **easier → harder**. Mix and match — your personal site can include several of these.

---

## Tier 1 — Great first projects (1–2 weeks each)

### 1. Personal website + journal ⭐ *recommended flagship*

Build a site about you with dated journal entries. Learn HTML, CSS, markdown, and GitHub Pages.

**AI helps with:** layout ideas, CSS styling, converting markdown to HTML, fixing broken tags.

**Stretch goals:** photo gallery, dark mode toggle, guestbook page.

---

### 2. AI study buddy

A simple page or script that turns your class notes into flashcards or quiz questions.

**AI helps with:** parsing notes, generating Q&A pairs, building a flip-card UI.

**Stretch goals:** export to Anki, track scores over time.

---

### 3. Book / movie review blog

Review things you read or watch. AI helps polish your writing — *you* pick the stars and write the opinion.

**AI helps with:** grammar, formatting, generating spoiler-free summaries you edit.

**Rule:** You write the review first. AI suggests edits; you accept or reject.

---

### 4. Family recipe book

Collect favorite recipes in markdown. Add photos, tags (vegetarian, quick, dessert), and a search box.

**AI helps with:** consistent formatting, unit conversion, print-friendly CSS.

---

## Tier 2 — Level up (2–3 weeks each)

### 5. Text adventure game

A choose-your-own-adventure game in the browser. Branching story, inventory, maybe pixel art.

**AI helps with:** story branches, JavaScript game logic, debugging state bugs.

**Stretch goals:** save/load progress, multiple endings tracker.

---

### 6. Hobby dashboard

One page that pulls together info about something you love — sports scores, anime release calendar, music charts, Minecraft mod list, etc.

**AI helps with:** API integration, caching, clean UI components.

**Note:** Many APIs need a free key — never commit the key; use environment variables.

---

### 7. Summer photo journal

Upload photos with captions. AI generates *draft* captions; you rewrite them in your voice.

**AI helps with:** responsive gallery, lazy loading, caption drafts.

---

### 8. Allowance / side-hustle tracker

Track money in and out. Charts for spending categories. Optional savings goals.

**AI helps with:** chart libraries, form validation, CSV export.

---

## Tier 3 — Ambitious summer builds (3+ weeks)

### 9. Automate a boring task

Pick something annoying: rename 500 photos, sort downloads, generate weekly meal plans from a pantry list.

**AI helps with:** Python or PowerShell scripts, error handling, scheduling.

**Claude Code shines here** — it can run commands and iterate in the terminal.

---

### 10. Multiplayer trivia night

Browser quiz game the family plays together. One person hosts; others join on phones.

**AI helps with:** WebSocket or Firebase realtime, question bank JSON, timer logic.

---

### 11. "Explain it to me" learning app

Paste a Wikipedia paragraph or textbook section; the app generates explanations at different levels (ELI5, normal, expert). *You* verify accuracy.

**AI helps with:** UI, API calls, prompt design.

**Important lesson:** AI can hallucinate facts. Always verify against the source.

---

### 12. Portfolio + résumé site (great for 16)

Professional landing page: projects, skills, contact form, downloadable PDF résumé.

**AI helps with:** responsive design, accessibility, SEO meta tags.

---

## Combo projects (best of both worlds)

| Combine | Result |
|---------|--------|
| Journal + photo journal | Travel log with maps and pictures |
| Study buddy + hobby dashboard | "F1 stats + physics flashcards" |
| Recipe book + review blog | Food critic site |
| Text adventure + journal | Interactive fiction about your summer |

---

## How to choose

Ask each person:

1. What do you already care about? (games, sports, art, music, school subjects)
2. Do you want something **visual** (website) or **practical** (script/tool)?
3. Do you want to work **together** on one thing or **separately** with occasional merges?

There's no wrong answer. The goal is to **ship something you can show someone** by end of summer.
